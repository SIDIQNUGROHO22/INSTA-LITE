Panduan Setup Supabase & Backup Media (Gratis)

InstaLite memakai Supabase (gratis tanpa kartu kredit) untuk Auth, Database PostgreSQL Realtime, dan Storage foto & video (1 GB):

  1. Buat project gratis di supabase.com.
  2. Buka menu SQL Editor, salin seluruh isi file supabase_schema.sql dari repo ini, lalu klik Run (otomatis membuat tabel, RLS, trigger profil, dan bucket instalite-media).
  3. Buka Project Settings > API, lalu tempel Project URL dan anon / publishable key ke file supabase.js: 
    export const SUPABASE_CONFIG = {
  url: "https://project-anda.supabase.co",
  anonKey: "anon_key_anda",
  storageBucket: "instalite-media"
};

Backup yang Disarankan: File versi Firebase sebelumnya tersimpan utuh di folder backup/firebase_cloudinary_backup/. Untuk cadangan media tambahan jika kuota 1 GB Supabase penuh, Anda juga dapat mengisi CLOUDINARY_BACKUP_CONFIG di supabase.js.
