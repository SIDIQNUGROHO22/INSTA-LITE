Panduan Konfigurasi Media Cloudinary (Gratis)

Agar fitur upload foto dan video dapat berfungsi tanpa biaya (paket Spark Firebase gratis), ikuti 3 langkah mudah berikut:

  1. Daftar akun gratis di cloudinary.com (100% gratis, tanpa kartu kredit).
  2. Buka Settings > tab Upload > scroll ke Upload presets > klik Add upload preset. Ubah Signing Mode menjadi Unsigned, lalu simpan.
  3. Buka file firebase.js di proyek ini, lalu isi: 
    export const CLOUDINARY_CONFIG = {
  cloudName: "nama_cloud_kamu",
  uploadPreset: "nama_preset_kamu"
};

Jika belum dikonfigurasi, Anda tetap dapat membuat postingan teks dengan mengosongkan pilihan foto/video.
